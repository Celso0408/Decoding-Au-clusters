**DimRedPy** is designed to be **domain-agnostic**, providing a consistent API for complex scientific data analysis while leveraging modern backends like PyTorch, openTSNE, umap-learn, and NVIDIA RAPIDS.

## 🏛 Framework Overview

DimRedPy is organized into several specialized sub-packages, all accessible via the `dimredpy` namespace.

### Shared Utilities

Behind the core algorithms, DimRedPy provides a highly optimized suite of tools for data preparation, metrics, and structural analysis.

| Sub-package | Core Purpose | Primary Imports |
|---|---|---|
| `dimredpy.shared.descriptors` | Geometric analysis tools for 3D point clouds and trajectories. | `coordination_histogram`, `radius_of_gyration`, `hausdorff_chirality_measure` |
| `dimredpy.shared.metrics` | Custom distance metric objects supporting pairwise computations and PBC. | `EuclideanMetric`, `PBCMetric`, `SphericalMetric` |
| `dimredpy.shared.transfer` | Mathematical kernels used by Sketch-map to transform distances. | `Sigmoid`, `Compress`, `XSigmoid`, `make_transfer` |
| `dimredpy.shared.io` | Memory-efficient loaders and writers for simulation trajectories. | `load_spatial_coordinates`, `load_tabular_data` |
| `dimredpy.shared.analysis` | Tools for measuring the quality of a dimensionality reduction mapping. | `distance_histogram`, `preservation_score` |
